Nasti privacy policy

Updated November 17, 2026

This policy covers the Nasti macOS desktop app and this GitHub Pages website. Xiaotong Wu maintains Nasti. Connecting a Google account is optional. You can use the local music library, the licensed Internet Archive catalog and the Vault without connecting an account.

Google and YouTube data we access

Nasti uses YouTube API Services for the YouTube Music playlist panel. After you agree to the privacy policy in Nasti and choose to sign in, Google handles account selection and asks for your permission in your system browser. Nasti receives an authorization code through a local connection on your Mac and exchanges that code with Google for OAuth access and refresh tokens. Nasti does not collect your Google password and does not request your email address or Google profile.

  • YouTube channel identifier. Nasti uses this identifier to associate saved playlists with the correct account and determine whether you can edit a playlist.
  • Playlist information. Nasti receives playlist identifiers, names, descriptions, visibility and ownership information so it can show and refresh your playlists and import the ones you choose.
  • Playlist entries. Nasti receives entry and video identifiers, titles, creator names and ordering information to display tracks, open tracks in YouTube Music and apply changes you request.

How Nasti uses this data

Nasti uses Google user data to provide the playlist features you use. It requests the youtube.force-ssl scope because playlist edits require a write permission. Google describes this scope broadly. Nasti calls YouTube Data API methods for channel lookup and playlist management. If you choose to create, rename, reorder, remove from or delete a playlist, Nasti sends the requested operation to YouTube.

Nasti’s use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. Nasti does not sell Google user data or use it for advertising, profiling, analytics or AI training.

Storage, protection and retention

Nasti keeps access tokens in memory and stores a refresh token in macOS Keychain so it can connect again. Nasti stores playlist snapshots you import in the local SQLite library on your Mac, with an account identifier and the time they were saved. Snapshots are deleted when they reach 30 days without a refresh and Nasti next opens the library or checks the saved playlist records. If Google revokes access, Nasti clears the account’s saved snapshots when it detects the invalid grant. Requests to Google and YouTube use HTTPS.

Sharing and service providers

The desktop app sends OAuth and YouTube API requests directly from your Mac to Google. There is no Nasti server that receives your Google tokens or playlist snapshots. If you open a track or playlist in YouTube Music, Nasti passes the relevant identifiers to your system browser to open the corresponding YouTube page. The Google Privacy Policy describes Google’s handling of these requests. When you change a playlist’s visibility, YouTube applies the setting you select.

GitHub serves this website and Nasti’s releases. Nasti checks GitHub for app updates. The desktop app uses Internet Archive for licensed media search, downloads and playback when you choose those features. These services receive the network requests needed to deliver their content. Nasti does not send Google OAuth tokens or playlist snapshots to GitHub or Internet Archive. This website does not use an app sign-in, analytics script or advertising script.

Delete your data or revoke access

  1. Use Remove local snapshot on a saved playlist to delete its copy from Nasti.
  2. Use Revoke access in Nasti’s YouTube Music account menu to revoke its Google permission and clear the account’s saved snapshots and token.
  3. Manage or remove Nasti access independently in your Google Account security settings.

Removing a local snapshot or revoking access leaves playlists on YouTube. To delete a playlist on YouTube, use YouTube or the separate Delete playlist action in Nasti.
