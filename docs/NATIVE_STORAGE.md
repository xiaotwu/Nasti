# 桌面版更新与存储

在「设置 → 关于」检查更新。Nasti 匿名读取本项目的 GitHub Releases，显示可安装的较新 Apple Silicon 版本。点击「更新并重启」后应用负责下载、安装和重新打开。Beta 安装可接收包含更新资产的较新 Beta 和稳定版。正式发行版的检查范围不包含 Beta。

更新包限制为 96 MiB。Nasti 验证钉住公钥的签名、签名绑定的版本、内嵌应用的 Developer ID 和本机 Gatekeeper 策略，再以同卷原子交换替换当前应用。更新程序不提权。若无法写入当前应用目录、处在磁盘映像或隔离转移路径，或当前安装和准备目录跨卷，可使用发布页的签名 DMG 手动升级。老版本需要手动安装一次包含更新器的版本。

| 位置 | 内容与上限 |
| --- | --- |
| `~/.nasti/cache/<应用标识>/` | 预留给应用管理的可重建缓存。当前桌面实现不在此持久化流媒体。 |
| `~/.nasti/tmp/<应用标识>/vault/` | Vault 正在写入或等待播放结束后释放的临时文件。与托管副本合计，沿用默认 256 MiB、最高 2 GiB 的 Vault 预算。 |
| `~/.nasti/tmp/<应用标识>/oauth/` | OAuth 客户端原子保存时的暂存位置。每个客户端输入限 64 KiB。 |
| `~/.nasti/tmp/<应用标识>/updater/` | 更新解包与短时旧应用副本。安装工作目录按逻辑字节限 256 MiB，仅在独占安装锁内清理应用明确标记的过期暂存。 |

曲库数据库、已存 Vault 媒体和 OAuth 配置继续使用应用原有数据目录。升级沿用应用标识与数据目录。系统 WebKit 缓存由 macOS 管理。开发验收的 `NASTI_DATA_DIR` 使用该隔离目录下的 `.nasti`。

发版时，对已签名、公证和附票的 `Nasti.app` 制作 `Nasti.app.tar.gz`。用保管在本机的更新私钥对归档签名并绑定 SemVer，上传 `Nasti.app.tar.gz`、`Nasti.app.tar.gz.sig` 及引用该标签资产的 `latest.json`。正式公开前验证清单、资产哈希、原图标和启动目录。在 GitHub 匿名下载验证更新后保留验收凭证。
