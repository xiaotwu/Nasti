在搭载 Apple 芯片的 Mac 上安装 Nasti，建立你的曲库。

安装 Nasti

  1. 前往 GitHub Releases，下载最新公开版本中适用于搭载 Apple 芯片的 Mac 的 DMG。
  2. 打开磁盘映像，把 Nasti 复制到「应用程序」，然后打开已安装的副本。
  3. Nasti 首次启动时显示空档案。通过顶栏检索曲目、导入歌单或打开设置。

建立曲库

从顶栏打开「检索」，在本地曲库或受支持的 Internet Archive 授权目录中查找曲目。也可以在「导入歌单」中粘贴支持的发行链接，预览后选择单曲，或按来源顺序导入整张歌单。

档案中的每列代表一张歌单。可从档案或歌单总览找到曲目。将符合条件的录音保存至离线储藏库，便可在无网络时播放。

YouTube Music

如果你的版本和账号支持此功能，请打开 YouTube Music 面板，阅读隐私政策与使用条款。同意后，可在系统浏览器登录并决定是否授权。连接账号是可选的。播放会在系统浏览器中打开 YouTube Music。

更新与支持

如应用支持自动更新，可在「设置 → 关于」检查更新。你也可以从 GitHub Releases 下载新版。请通过项目问题区报告问题，注明应用版本及 macOS 版本。请勿在公开报告中附上私人歌单或账号信息。
