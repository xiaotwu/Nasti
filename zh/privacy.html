本政策说明你使用 Nasti macOS 应用或访问其 GitHub Pages 网站时，Nasti 如何处理信息。Nasti 由 Tony（@xiaotwu）维护。你无需连接 Google 账号，即可使用本地曲库、Internet Archive 授权目录和离线储藏库（Vault）。

Google 和 YouTube 数据

Nasti 的可选 YouTube Music 歌单面板使用 YouTube API 服务。在启用 Google 登录的版本中，面板会请你阅读并同意本政策与 Nasti 使用条款，然后才会向 YouTube API 发送请求。接下来，你可在系统浏览器打开的 Google 同意页面单独决定是否授权 Nasti。如果拒绝，本地曲库、授权目录和离线储藏库仍可使用。

你授权后，Google 会将短期有效的授权码返回到你的 Mac。Nasti 仅用它换取一次 OAuth 令牌。Nasti 不请求你的 Google 邮箱或个人资料，也不会接收 Google 密码或访问浏览器中的 Google 会话 Cookie。

Nasti 从 Google 和 YouTube 接收以下数据。

  • 授权数据。 Nasti 使用授权码和 OAuth 令牌，在你的授权范围内向 YouTube API 发出请求。
  • YouTube 频道标识符。 Nasti 用它判断你可以编辑哪些歌单，并将本地保存的歌单副本与相应账号关联。
  • 歌单信息。 Nasti 使用标识符、标题、描述、可见性和归属信息列出和刷新歌单。调整曲序前会核对条目数量，更新歌单详情时会保留默认语言、播客状态等原有设置。
  • 歌单条目。 Nasti 使用条目和视频标识符、标题、创作者信息及曲序来显示歌单、在 YouTube Music 中打开曲目，或执行你选择的编辑操作。

Nasti 请求访问权限的原因

YouTube 要求拥有写入权限才能编辑歌单，因此 Nasti 请求 https://www.googleapis.com/auth/youtube.force-ssl。Google 同意页面列出的权限范围比歌单编辑更广。Nasti 用它查询频道、读取歌单并执行你发起的更改，包括创建歌单、编辑详情或可见性、添加或移除条目、调整曲序，以及删除歌单。Nasti 不使用该权限编辑或删除视频、评分、评论或字幕。

Nasti 对通过 Google API 获得的信息的使用遵守 Google API 服务用户数据政策，包括其中的「有限使用」要求。Nasti 将这些数据用于本政策所述的歌单功能。Nasti 不出售 Google 用户数据，也不将其用于广告、用户画像、分析或 AI 训练。

存储和保护

Nasti 通过 HTTPS 向 Google 和 YouTube 发送请求。授权回调在你的 Mac 上完成，Nasti 使用 PKCE 保护令牌交换。

  • 授权码。 只用于交换令牌，不保存到本地曲库。
  • 访问令牌和刷新令牌。 Nasti 将短期访问令牌保存在内存中，并通过 macOS 钥匙串保存刷新令牌，用于重新连接。撤销授权成功后会移除刷新令牌。如果 Google 报告授权无效，Nasti 会尝试移除失效的令牌。
  • 已保存的歌单快照。 导入歌单时，Nasti 将歌单详情、条目、关联的频道标识符和保存或刷新时间写入 Mac 上的 SQLite 曲库。导入并不下载 YouTube 录音。连续 30 天未刷新的快照会在下次打开曲库或读取已保存的歌单记录时移除。

Nasti 将本地曲库、Vault 中符合条件的录音副本以及应用偏好保存在你的 Mac 上。应用还会在本机记录你是否已同意适用于 YouTube Music 功能的本政策。

数据共享与服务提供方

  • Google 和 YouTube 直接接收来自你 Mac 的 OAuth 和歌单请求。在 YouTube Music 中打开曲目或歌单时，Nasti 将相关标识符交给系统浏览器，以打开对应页面。Google 和 YouTube 按照 Google 隐私权政策处理其服务产生的数据和浏览器 Cookie。
  • GitHub 托管本网站及应用发行文件。检查或下载更新时，应用会连接 GitHub。GitHub 按其隐私声明处理对这些服务的请求。
  • Internet Archive 在你使用其目录时接收搜索查询、条目请求，以及下载或播放请求。请参阅 Internet Archive 使用条款与隐私政策。

Nasti 没有接收 Google 令牌或歌单快照的应用服务器。授权数据和执行所选操作所需的歌单数据由应用直接发送给 Google 和 YouTube。打开 YouTube Music 链接时，应用把对应的歌单或视频标识符交给浏览器。Nasti 不会将 Google 用户数据发送给 GitHub、Internet Archive、广告或分析服务提供方。

本网站在你的浏览器中保存所选主题。站内搜索在浏览器中运行，搜索词不会发送给 Nasti。Nasti 未在本网站添加广告或分析脚本。

删除记录或撤销授权

  1. 如需删除一条本地歌单记录，在 YouTube Music 面板选择移除本地记录。该歌单仍保留在 YouTube 上。
  2. 如需停止 Nasti 访问并移除已保存的账号数据，在面板的 Google 账号菜单中选择撤销授权。Nasti 会请求 Google 撤销授权，并在撤销成功时移除该账号的令牌和本地快照。
  3. 如果 Nasti 无法连接 Google 并完成撤销，请在联网后重试。你也可以在 Google 账号安全设置中撤销。随后联网并重新打开 Nasti 的 YouTube Music 面板，让应用检查授权。检测到授权失效后，Nasti 会清除关联的本地快照。

如需从 YouTube 删除所选歌单，使用单独的删除在线歌单操作。移除 Vault 中的本地副本可释放 Mac 上的存储空间。

联系方式与政策更新

如有疑问、投诉，或需要协助删除数据，请通过 Nasti 问题跟踪页面联系 Tony。GitHub Issues 中的报告会公开显示。请勿在报告中填写账号详情、私人歌单内容、密码、授权码或令牌。

本政策版本以上方的生效日期为准。如果 Nasti 将 Google 用户数据用于新的目的，或需要访问更多 Google 用户数据，应用会在实施该变更前征求你对更新后政策的同意。
